# 🚀 Ramu - Quick Start Guide

## ⚡ 5-Minute Setup

### Step 1: Install & Grant Permissions (2 minutes)
1. Install the APK on your phone
2. Open Ramu app
3. Grant ALL permissions when asked:
   - ✅ Microphone
   - ✅ Contacts
   - ✅ Phone
   - ✅ Bluetooth

### Step 2: Enable Accessibility Service (1 minute)
1. Go to **Settings** → **Accessibility**
2. Find **"Ramu"** in the list
3. Turn it **ON**
4. Confirm when asked

### Step 3: Test Basic Commands (2 minutes)
Press the mic button and say:

```
"Ramu hello"
"Ramu open WhatsApp"
"Ramu turn on Bluetooth"
```

## 🐛 Troubleshooting

### Problem: "Commands not working"
**Solution:**
1. Check if you said "Ramu" first
2. Check internet connection
3. Speak clearly and slowly
4. Try rephrasing the command

### Problem: "WhatsApp automation not working"
**Solution:**
1. Enable Accessibility Service (Settings → Accessibility → Ramu → ON)
2. Make sure WhatsApp is installed
3. Update WhatsApp to latest version

### Problem: "Can't hear me"
**Solution:**
1. Grant microphone permission
2. Check if mic is working in other apps
3. Reduce background noise
4. Speak closer to phone

### Problem: "App not opening"
**Solution:**
1. Make sure app is installed
2. Try saying full app name: "Instagram" not "Insta"
3. Update the app to latest version

## 💡 Pro Tips

### 1. Use Natural Language
You can say commands in multiple ways:
- "Ramu WhatsApp open karo"
- "Ramu WhatsApp kholo"
- "Ramu open WhatsApp"
All work the same!

### 2. Chain Multiple Actions
```
"Ramu Instagram open karo, Rahul search karo, aur like karo"
```
Ramu will do all steps automatically!

### 3. Mix Languages
```
"Ramu Instagram open karo aur Rahul को search करो"
```
Hindi + English mix works perfectly!

### 4. Use Background Service
Tap "Start Service" button to keep Ramu always listening in background.

### 5. Be Patient
Wait 2-3 seconds after app opens before next action.

## 🔒 Privacy & Security

### What Ramu Can Access:
- ✅ Microphone (for voice commands)
- ✅ Contacts (for calls/messages)
- ✅ Phone (for making calls)
- ✅ Screen content (via Accessibility - only when you command)

### What Ramu CANNOT Do:
- ❌ Record conversations
- ❌ Access your data without permission
- ❌ Send data to servers
- ❌ Work without your command

**Your privacy is 100% protected!**
