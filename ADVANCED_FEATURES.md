## 🗣️ Wake Word: "Ramu"

**IMPORTANT:** Har command ke pehle "Ramu" bolna zaroori hai!

### Examples:
✅ **Correct:**
- "Ramu WhatsApp open karo"
- "Ramu call John"
- "Ramu turn on Bluetooth"

❌ **Wrong (Won't Work):**
- "WhatsApp open karo" (No wake word)

## 🎓 Usage Tips

### 1. **Speak Clearly**
- Use normal speaking pace
- Pronounce words clearly
- Avoid background noise

### 2. **Use Wake Word**
- Always start with "Ramu"
- Wait for mic to activate
- Then speak your command

### 3. **Be Specific**
- Use exact contact names
- Mention app names clearly
- For messages, speak the full text

### 4. **Multi-Step Commands**
- You can combine actions
- Example: "Ramu WhatsApp open karo aur Rahul ko hello bhejo"
- Ramu will execute steps in order

### 5. **Accessibility Service**
- Must be enabled for WhatsApp automation
- Required for navigation commands
- Enable in Settings → Accessibility → Ramu

## 🔧 Troubleshooting

### Command Not Working?

1. **Check Wake Word**
   - Did you say "Ramu" first?
   - Try: "Ramu [your command]"

2. **Check Permissions**
   - Microphone: Required
   - Contacts: For calls/messages
   - Accessibility: For WhatsApp automation

3. **Check Internet**
   - Voice recognition needs internet
   - Ensure stable connection

4. **Rephrase Command**
   - Try different words
   - Use simpler sentences
   - Check examples above

### WhatsApp Automation Not Working?

1. **Enable Accessibility Service**
   - Settings → Accessibility
   - Find "Ramu" service
   - Turn it ON

2. **WhatsApp Must Be Installed**
   - Check if WhatsApp is installed
   - Update to latest version

3. **Contact Name Must Match**
   - Use exact name from contacts
   - Or close variation
