## 📋 Complete Command Patterns

### Pattern 1: Open + Search
```
"Ramu [App] open karo aur [query] search karo"

Examples:
- "Ramu Instagram open karo aur Rahul search karo"
- "Ramu YouTube open karo aur songs search karo"
- "Ramu Amazon open karo aur laptop search karo"
```

### Pattern 2: Open + Action
```
"Ramu [App] open karo aur [action] karo"

Examples:
- "Ramu Instagram open karo aur like karo"
- "Ramu YouTube open karo aur play karo"
- "Ramu Gmail open karo aur compose karo"
```

### Pattern 3: Open + Action + Target
```
"Ramu [App] open karo [target] ko [action] karo"

Examples:
- "Ramu Gmail open karo john@example.com ko email bhejo"
- "Ramu WhatsApp open karo Rahul ko message bhejo"
- "Ramu Instagram open karo Priya ki profile dekho"
```

### Pattern 4: Open + Action + Content
```
"Ramu [App] open karo aur [action] karo [content]"

Examples:
- "Ramu Facebook open karo aur post karo feeling happy"
- "Ramu Twitter open karo aur tweet karo hello world"
- "Ramu Instagram open karo aur comment karo nice pic"
```

## 🔧 How It Works

### 1. **App Detection**
Ramu automatically detects which app is open:
- WhatsApp → WhatsApp automation
- Instagram → Instagram automation
- YouTube → YouTube automation
- Any other app → Generic automation

### 2. **Action Recognition**
Ramu understands these actions:
- **search** - Search for something
- **click** - Click a button/element
- **type** - Type text
- **like** - Like post/video
- **comment** - Add comment
- **share** - Share content
- **play** - Play video/music
- **pause** - Pause video/music
- **compose** - Create new post/email
- **send** - Send message/email

### 3. **Smart Automation**
- Finds buttons automatically
- Types text in correct fields
- Clicks appropriate elements
- Handles multi-step flows

## 🐛 Troubleshooting

### Command Not Working?

1. **Enable Accessibility Service**
   - Settings → Accessibility → Ramu → Turn ON
   - This is REQUIRED for app automation

2. **App Must Be Installed**
   - Make sure the app is installed
   - Update to latest version

3. **Use Exact Button Names**
   - Say "like" not "thumbs up"
   - Say "search" not "find"
   - Say "play" not "start"

4. **Wait for App to Load**
   - Give app 2-3 seconds to open
   - Then speak next command

### App-Specific Issues

**Instagram:**
- Make sure you're logged in
- Profile must be public or you must be following

**YouTube:**
- Ads may interfere - skip them first
- Some videos may be age-restricted

**Gmail:**
- Must be logged into account
- Recipient email must be valid
